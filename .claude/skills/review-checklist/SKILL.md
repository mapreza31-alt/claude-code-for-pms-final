# Review checklist

The student is pointing you at a brief. Check it against the four items below and report back. You're a reviewer, not an editor: don't change the brief unless the student asks you to afterwards.

## 1. Find and read the brief

- Use the file, wiki page or pasted text the student named. If they named nothing and it isn't obvious from the conversation, ask which brief in one short question.
- Read the whole brief before judging anything. Stay within the brief itself; don't go looking for other sources unless the student asks.

## 2. Check the four items

For each item, decide **Pass**, **Partly** or **Missing**, and quote the line (or name the section) that led you there. If something is missing, say where in the brief it would naturally go.

1. **Names who owns it.** A named person (not just a team or "TBD") is accountable for the brief or the work. A former owner who has left, or a placeholder name, counts as Partly.
2. **Says how we'll know it worked.** There's at least one measure of success: a metric with a target or direction, a date, or an observable outcome for users. "Improve the experience" with nothing checkable is Missing. A metric with no baseline or target is Partly.
3. **Keeps the same scope start to finish.** The scope promised at the top matches what the body and any plan, phasing or asks at the end describe. Flag scope creep (new items appearing later), scope that quietly shrinks, or goals and asks that don't line up. Name the specific items that drift.
4. **Explains the problem before the fix.** The brief says what's wrong, for whom, and how we know (evidence) before it proposes a solution. A brief that opens with the solution, or never states the problem, fails this item.

## 3. Report

Keep it short and in plain language. Use this shape:

```
Review: <brief name>

| Check | Result | Evidence |
|---|---|---|
| Owner named | Pass / Partly / Missing | "<short quote>" or section |
| Success measure | ... | ... |
| Consistent scope | ... | ... |
| Problem before fix | ... | ... |

Biggest gap: <one sentence on the most important thing to fix first>

Suggested fixes:
- <one concrete fix per item that wasn't a Pass>
```

- Keep quotes short (a phrase, not a paragraph).
- If everything passes, say so plainly and skip "Suggested fixes".
- End by offering to make the fixes, but don't make them unless the student says yes.
